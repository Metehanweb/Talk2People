# Talk2People

>TeamSpeak benzeri gerçek zamanlı iletişim platformu (MVP)

## Teknoloji Stack

| Katman | Teknoloji |
|---|---|
| Backend | NestJS (JavaScript modu) |
| Veritabanı | MongoDB (Mongoose) |
| Web Frontend | Next.js (JS/JSX) |
| Mobil Frontend | React Native + Expo (JS/JSX) |

> ⚠️ TypeScript kullanılmaz. Tüm dosyalar `.js` veya `.jsx` uzantılıdır.
